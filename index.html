雀魂教练

说清楚：这是作弊工具。

它读你的对局数据，在你切牌前给出答案。开了实时模式，你摸牌它就说打哪张。
不掩饰。要不要用，你自己判断。

下载 Windows 安装包 v1.1.0

152 MB · 免管理员 · Chrome/Edge + Tampermonkey · Windows 10/11

实时模式摸牌即建议，默认关闭，开了它会在你切牌前说话。
复盘模式切完牌才给评价：这一手 AI 会怎么打、你打的排第几。
魂天水平Mortal-S42 完整权重（192×40），不是精简版。每手几十毫秒，全在本机 CPU。

为什么装这个而不是别的

本项目自动打牌类（如 MahjongCopilot）
一键启动安装包四步，托盘常驻装 Python + Playwright + 浏览器
替不替你打不，点牌永远是你自己会，自动点击出牌
MITM 证书不装要装并信任
系统代理不改要改
网络请求只在本机 127.0.0.1经过中间人代理

少了这几样，不等于安全——只是系统里少三个会出问题的地方。

长什么样

实时模式：摸牌即给建议

复盘模式：切完牌才说话

风险自负。读对局数据这件事，本身就踩在《雀魂用户协议》的边上。我不承诺你不会被封，也给不了任何保证。
